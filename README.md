Cafeteria Sábia

Projeto de um site para uma cafeteria fictícia, desenvolvido com HTML, CSS e JavaScript, com foco em layout moderno, responsividade e interatividade.

Status do Projeto:
Em desenvolvimento
Algumas funcionalidades ainda estão sendo implementadas e outras serão alteradas.

Tecnologias Utilizadas:
HTML5: Estrutura das páginas
CSS: Estilização e layout responsivo
JavaScript: Interações e dinamismo
Google Fonts

Objetivo do Projeto
Estudo das linguagens de marcação para desenvolver minhas habilidades.
Aprender mais sobre oganização de código e estrutura de pastas.
Desenvolver mais minha capacidade de programação em javascript.
